# R1-Z Pico Tachometer

Yamaha R1-Z(2ストローク並列2気筒)用に、Raspberry Pi Picoでイグニッションコイルのパルス信号から回転数を計算し、表示・出力するプロジェクトです。

現在はWokwi上でのシミュレーション段階で、SSD1306 OLEDへの表示部分まで動作確認済みです。

## 構成

- **入力**：IGコイルのパルス信号をPicoのGPIOでカウント → RPM計算
- **表示**：SSD1306 OLED(128x64, I2C)に起動画面(YAMAHA / R1-Z)を10秒表示後、回転数(rpm)を表示
- **出力(予定)**：計算したRPMをPWMでパルス再生成し、MOSFET経由で純正アナログタコメーター(2線式)を駆動

## ファイル構成

| ファイル | 内容 |
|---|---|
| `main.py` | メインプログラム。パルスカウント・RPM計算・OLED表示 |
| `ssd1306.py` | SSD1306 OLED用ディスプレイドライバ |
| `diagram.json` | Wokwiの回路図(パーツ配置・配線情報) |

## 配線

| 部品 | ピン | 接続先(Pico) |
|---|---|---|
| SSD1306 | GND | GND |
| SSD1306 | VCC | 3V3(OUT) |
| SSD1306 | SCL | GP1 |
| SSD1306 | SDA | GP0 |
| パルス入力(実車ではIGコイル、Wokwi上ではClock Generatorでスタブ) | OUT | GP16 |
| パルス入力 | GND | GND |

実車に組み込む際は、IGコイル側にツェナーダイオードやフォトカプラ等の保護回路を挟むこと(直結厳禁)。

## Wokwiでの動かし方

1. https://wokwi.com/projects/new/micropython-pi-pico で新規プロジェクトを作成
2. `main.py` と `ssd1306.py` をこのリポジトリの内容で作成・貼り付け
3. パーツを配置：SSD1306、Clock Generator(パルスのスタブ用)
4. 上記の配線表の通りに配線
5. 再生ボタンで実行。Clock Generatorの周波数(Hz)を変えるとRPM表示が連動する

### 周波数とRPMの関係(現状のコード)

1回転あたり1パルス(R1-Zの片側IGコイルのみ計測を想定)の場合：

```
RPM = 周波数(Hz) × 60
```

例：50Hz → 3000rpm相当

## 現在の状態・既知の制限

- パルスのサンプリングは200msごとの単純カウント方式のため、低回転域(アイドリング付近)では量子化誤差が出やすい(例：17Hz入力で理論値1020rpmに対し表示1008rpm程度のブレ)
- 高周波数(数kHz以上)ではMicroPythonの割り込み処理が追いつかず、パルスを取りこぼして不正確な値になる。実際のエンジン回転域(〜10,000rpm程度、周波数にして数百Hz以下)であれば問題ない想定
- 出力側(MOSFETでの純正タコメーター駆動)は未実装。設計方針のみ決定済み
- 実車のIGコイル信号を受けるための保護回路(ツェナー/フォトカプラ)は未実装。Wokwi上のスタブ入力での検証のみ
